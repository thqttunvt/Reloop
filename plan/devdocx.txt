1. HỆ THỐNG ĐANG CÓ GÌ (đọc 5 phút)
=====================================================================
ReLoop: chợ đồ điện tử cũ, hỏng. Người bán đăng tin kèm ảnh → AI gợi ý thông tin →
hệ thống tìm đơn vị thu mua trong 5 km → báo giá → giao dịch, bàn giao, đánh giá 2 chiều.

Người dùng:
  • Khách xem      : mọi người đã đăng nhập — lướt Chợ, nhắn tin người bán.
  • Đối tác cấp 1  : khách lẻ (cá nhân / hộ KD / DN) — ĐƯỢC ĐĂNG TIN, không thu mua (QĐ-34).
  • Đối tác cấp 2  : doanh nghiệp / hộ kinh doanh — đăng tin + chi nhánh, bảng giá, báo giá, thu mua.
  • Admin          : duyệt đối tác, duyệt tin bị gắn cờ, tranh chấp, báo cáo vi phạm.

Kiến trúc (serverless AWS, ap-southeast-1, account 926583575243):
  Web React (S3 + CloudFront) → API Gateway HTTP API (JWT Cognito) → 1 Lambda Node 22
  → DynamoDB single-table "reloop-core-table" (PK/SK + GSI1)
  Phụ trợ: S3 ảnh (presigned POST) · Rekognition (kiểm duyệt ảnh + đọc chữ) ·
           Bedrock Amazon Nova Pro (AI phân tích ảnh) + Guardrail · EventBridge 15 phút (job nền) ·
           CloudWatch (dashboard, 8 alarm).
  Thanh toán: OFFLINE (hai bên trả tiền khi gặp). Code ví / sổ cái vẫn giữ, chưa nối.
  Doanh thu (QĐ-37): đăng tin miễn phí; người bán trả 10.000đ / giao dịch hoàn tất, hóa đơn gộp theo
  tháng (ngày 1), chuyển khoản theo mã RLFxxxxxx, Admin tài chính xác nhận; quá hạn 7 ngày khóa đăng tin.

Bản đồ thư mục:
  backend/src/app.ts            lắp adapter theo môi trường (local ↔ aws)
  backend/src/http/routes.ts    TẤT CẢ API ở một file
  backend/src/modules/*         nghiệp vụ: users, partners, listings, transactions, chat, ai, billing,
                                notifications, reputation, reports, locations, jobs, wallet
  backend/src/store/keys.ts     TẤT CẢ khóa DynamoDB ở một file
  backend/src/domain/           state machine Listing / Quote / Transaction, danh mục
  backend/src/storage, ai/      S3, Rekognition, Bedrock (adapter — nghiệp vụ không gọi AWS trực tiếp)
  backend/test/                 vitest (107 test)
  frontend/src/pages, lib/      React; lib/api.ts = kiểu dữ liệu + gọi API; lib/catalog.ts = nhãn tiếng Việt
  infra/*.tf                    Terraform; infra/deploy.sh = build + apply + upload web
  scripts/                      smoke-aws.py (test trên AWS), make-admin.sh, loadtest.mjs

2. CÀI ĐẶT & CHẠY
=====================================================================
Chạy local (không cần AWS, không có ảnh / AI):
  npm install
  cp backend/.env.example backend/.env
  npm run dev:be        → API http://localhost:3001 (dữ liệu lưu backend/.data/db.json)
  npm run dev:fe        → Web http://localhost:5173 — chọn Owner / Partner / Admin để đăng nhập giả
  npm test              → test backend (phải xanh trước khi mở PR)
  npm run typecheck     → typecheck backend + frontend

Làm việc với AWS (chỉ người có quyền, xem vai trò OPS):
  Cần: AWS CLI ≥ 2.32, Terraform ≥ 1.10, Node 22+.
  aws login --profile reloop --region ap-southeast-1
  AWS_PROFILE=reloop bash infra/deploy.sh             # build backend → terraform apply → upload web
  AWS_PROFILE=reloop bash infra/deploy.sh frontend    # chỉ web
  AWS_PROFILE=reloop AWS_REGION=ap-southeast-1 python scripts/smoke-aws.py
  AWS_PROFILE=reloop bash scripts/make-admin.sh <email> --finance
  ⚠ Không dùng profile mặc định của máy cho ReLoop. Không commit .env, khóa AWS.

Web dev: https://d1cjl1tvcp0r6q.cloudfront.net (đã deploy bản nhánh feature/doi-tac-2-cap ngày 19/10)

Nguyên tắc code (bắt buộc — reviewer kiểm tra):
  1. Đổi trạng thái phải qua stateMachines.ts (assertTransition). Không gán status tay.
  2. Ghi DynamoDB có điều kiện version (putVersioned) + withOptimisticRetry.
  3. Không Scan. Khóa mới thêm vào store/keys.ts, có access pattern rõ ràng.
  4. Nghiệp vụ không gọi AWS SDK trực tiếp → tạo interface + bản thật + bản tắt/giả (như ImageStore).
  5. Việc nền phải idempotent: chạy trễ / chạy trùng không sai.
  6. API tạo dữ liệu quan trọng bắt buộc Idempotency-Key (đăng tin, chọn offer, gửi offer).
  7. Tiền là số nguyên VND; mọi thay đổi số dư qua Ledger.post().
  8. Lỗi nghiệp vụ trả mã ổn định (AppError code) để frontend hiện đúng.
  9. Không log token, mật khẩu, SĐT, STK đầy đủ.
 10. Quyết định nghiệp vụ mới → ghi QĐ-xx vào plan/quyetdinh.txt trước khi code.
